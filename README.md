# Community of Christ Scripture Study Platform 🌟

A visually stunning, AI-powered platform for studying Community of Christ scriptures featuring four incredible prototype experiences.

## ✨ Features

### 1. 📖 Immersive Scripture Reader
- **Focus Mode**: Blurs surrounding verses to enhance concentration
- **Adaptive Typography**: Font size adjustment and reading mode presets
- **Scroll-Driven Animations**: Beautiful fade-in effects as you read
- **Ambient Backgrounds**: Floating particles and gradient animations
- **Dark Mode**: Easy on the eyes for night reading
- **Progress Indicator**: Visual progress bar showing chapter completion

### 2. 🤖 AI Study Assistant
- **Conversational Interface**: Natural chat experience with AI
- **Context-Aware**: Understands which verse you're studying
- **Smart Suggestions**: Pre-generated questions to spark exploration
- **Citations**: Referenced verses linked inline
- **Voice Input**: Speak your questions (coming soon)
- **Verse Selection**: Switch between verses seamlessly

### 3. 🕸️ Scripture Network Visualization
- **Interactive 3D Graph**: Explore cross-reference connections visually
- **Color-Coded**: Different scripture collections have distinct colors
- **Connection Types**: Thematic, prophecy, quotation relationships
- **Click to Explore**: Select nodes to see verse details and connections
- **Filter Options**: View all scriptures or filter by collection
- **Beautiful Animation**: Smooth transitions and hover effects

### 4. 🎨 AI Verse Card Generator
- **Multiple Styles**: Gradient, Minimalist, Ornate, Modern, Photographic
- **Canvas Rendering**: High-quality image generation
- **Export Formats**: Instagram Post/Story, Twitter, Wallpaper
- **Mood-Based Design**: Colors adapt to verse themes
- **One-Click Download**: Save beautiful verse cards
- **Live Preview**: See changes in real-time

## 🚀 Tech Stack

- **Framework**: Next.js 14 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Visualization**: D3.js, React Force Graph
- **Canvas API**: For verse card generation

## 🎯 Getting Started

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the application.

### Project Structure

```
src/
├── app/
│   ├── globals.css          # Global styles
```

## 🎨 Design Philosophy

- **Sacred Minimalism**: Clean, reverent design that honors scripture
- **Delightful Interactions**: Micro-animations that enhance without distracting
- **Visual Hierarchy**: Typography-first design for readability
- **Immersive Storytelling**: Transform scripture study into a visual journey
- **Adaptive Beauty**: Design that responds to content and context

## 📱 Features Overview

### Immersive Reader
Perfect for deep study sessions. The focus mode helps you concentrate on one verse at a time while the beautiful animations make reading a peaceful experience.

### AI Assistant
Your personal study companion. Ask questions about historical context, find related verses, or get simple explanations - all in a beautiful conversational interface.

### Scripture Network
See the connections between scriptures come to life. Explore how Book of Mormon verses relate to D&C sections and Inspired Version passages through an interactive 3D visualization.

### Verse Card Generator
Create beautiful shareable verse cards with AI-powered design. Perfect for social media, wallpapers, or printing. Multiple styles and formats available.
